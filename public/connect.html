AI 연결 (MCP)

← 그래프로 돌아가기

Claude, Cursor 같은 AI 도구가 이 그래프를 읽고 고칠 수 있도록 MCP(Model Context Protocol) 서버를 열어 두었습니다. 아래 주소를 AI 도구의 MCP 설정에 넣으면 됩니다. 브라우저 안의 AI 에이전트는 WebMCP로 그래프 페이지를 바로 쓸 수 있습니다.

https://titan-graph.robocast.workers.dev/mcp

방식: Streamable HTTP · 서버 상태: 확인 중

권한

연결 방법할 수 있는 일
주소만 넣기 (토큰 없음)읽기 그래프 개요, 검색, 노드 보기, 메모·휴지통·변경 기록 보기, JSON-LD 내보내기
Authorization: Bearer <MCP_TOKEN> 헤더 추가쓰기 위 기능 + 노드·관계·메모 추가, 수정, 삭제, 복원, 수정 되돌리기

AI가 바꾼 내용은 변경 기록에 AI (MCP)로 남고, 삭제한 것은 휴지통에서 되살릴 수 있습니다. 쓰기 토큰은 웹 편집 비밀번호와 따로 관리합니다.

쓰기 토큰 만들기 (관리자, 한 번만)

  1. 아래 버튼으로 긴 무작위 토큰을 만들어 복사합니다. 토큰은 이 브라우저 안에서만 만들어지고 어디에도 전송되지 않습니다.
  2. Cloudflare 대시보드 → Workers & Pages → titan-graph → Settings → Variables and Secrets → Add에서 Type을 Secret, 이름을 MCP_TOKEN으로 넣고 Deploy합니다.
  3. AI 도구 설정의 <MCP_TOKEN> 자리에 같은 값을 넣습니다.
버튼을 누르면 토큰이 여기에 나옵니다

도구별 연결 방법

읽기만 할 때는 헤더 부분을 빼면 됩니다.

Claude Code (터미널)

터미널에서 한 줄로 추가합니다.

claude mcp add --transport http titan-graph {URL} --header "Authorization: Bearer <MCP_TOKEN>"

추가한 뒤 Claude Code 안에서 /mcp를 입력하면 연결 상태와 도구 목록을 볼 수 있습니다.

Claude 웹·데스크톱 앱 (사용자 지정 커넥터)

  1. Claude 앱의 설정 → 커넥터에서 사용자 지정 커넥터 추가를 고릅니다.
  2. 이름은 titan-graph, 주소는 위의 MCP 주소를 넣습니다.
  3. 대화창의 도구 메뉴에서 titan-graph를 켜고 사용합니다.

커넥터 화면에는 헤더를 넣는 칸이 없어 기본은 읽기 전용입니다. 쓰기가 꼭 필요하면 주소 끝에 ?token=<MCP_TOKEN>을 붙여 넣을 수 있습니다. 이때는 그 주소를 아는 사람 누구나 그래프를 고칠 수 있으니 공유하지 마세요.

Cursor

~/.cursor/mcp.json(모든 프로젝트) 또는 프로젝트의 .cursor/mcp.json에 넣습니다.

{
  "mcpServers": {
    "titan-graph": {
      "url": "{URL}",
      "headers": { "Authorization": "Bearer <MCP_TOKEN>" }
    }
  }
}

VS Code (GitHub Copilot 에이전트 모드)

프로젝트의 .vscode/mcp.json에 넣습니다.

{
  "servers": {
    "titan-graph": {
      "type": "http",
      "url": "{URL}",
      "headers": { "Authorization": "Bearer <MCP_TOKEN>" }
    }
  }
}

원격 HTTP MCP를 지원하는 도구

MCP 서버 주소(URL)와, 쓰기가 필요하면 Authorization 헤더를 넣는 칸을 찾아 위 값을 입력합니다.

로컬(stdio) MCP만 지원하는 도구

mcp-remote로 원격 서버를 로컬 서버처럼 이어 줍니다 (Node.js 필요). 예: Claude 데스크톱의 claude_desktop_config.json

{
  "mcpServers": {
    "titan-graph": {
      "command": "npx",
      "args": ["-y", "mcp-remote", "{URL}", "--header", "Authorization: Bearer <MCP_TOKEN>"]
    }
  }
}

직접 시험해 보기 (curl)

curl -s {URL} \
  -H "Content-Type: application/json" \
  -H "Accept: application/json, text/event-stream" \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'

브라우저 AI 에이전트 (WebMCP)

위의 MCP 서버와 별개로, 그래프 페이지 자체가 WebMCP(W3C Web Machine Learning 커뮤니티 그룹 초안) 방식으로 도구를 등록합니다. 브라우저에 들어 있는 AI 에이전트가 페이지를 연 채로 그래프를 검색하고, 화면에서 노드를 보여 주고, 메모를 붙일 수 있습니다.

  • 설정 없음: 서버 주소나 토큰을 넣을 필요가 없습니다. 페이지를 열면 document.modelContext.registerTool()로 도구가 등록됩니다.
  • 권한: 읽기 도구(search_nodes, get_node, show_node, list_notes)는 항상, 쓰기 도구(메모·노드·관계 추가·수정·삭제)는 그 브라우저에서 편집 로그인했을 때만 등록됩니다.
  • 반영: 에이전트가 바꾼 내용은 로그인한 이름으로 변경 기록에 남고, 화면에 바로 반영됩니다.
  • 지원 브라우저: WebMCP는 아직 초안이라 Chrome의 실험 기능(미리보기·오리진 트라이얼)에서만 동작합니다. 지원하지 않는 브라우저에서는 아무 일도 일어나지 않습니다. 등록되면 그래프 페이지 오른쪽 패널 아래에 "WebMCP 도구 N개를 등록했습니다"라고 표시됩니다.
